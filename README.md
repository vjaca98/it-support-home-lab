
# IT Support Home Lab

A practical portfolio project focused on IT support, troubleshooting, incident management, and technical documentation.

## About This Project

This home lab was created to refresh and strengthen my IT knowledge through practical scenarios based on common IT Service Desk and IT Support tasks.

It includes simulated support tickets, troubleshooting guides, and technical documentation.

## Project Objectives

- Practice structured IT troubleshooting.
- Understand incident management processes.
- Document technical issues and resolutions.
- Improve knowledge of Windows operating systems.
- Develop IT Service Desk and user support skills.

## Skills & Technologies

- Windows 11 troubleshooting
- IT Service Management (ITSM)
- Incident and problem management
- Account and access management concepts
- Basic networking
- Technical documentation
- Microsoft Active Directory concepts
