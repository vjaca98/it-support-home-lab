
# INC-001: Windows Login Failure

## 1. Ticket Information

- **Ticket ID:** INC-001
- **Category:** Account and Access
- **Priority:** Medium
- **Status:** Resolved
- **Environment:** Windows 11 (Simulated)
- **Date:** 18 November 2026

## 2. Problem Description

A user reports that they cannot log in to their Windows computer. After entering their username and password, an error message appears stating that the account is locked.

## 3. Initial Investigation

The following checks were performed:

1. Verified that the username was entered correctly.
2. Checked the keyboard layout and Caps Lock.
3. Confirmed that the computer had network connectivity.
4. Reviewed the simulated account status.

## 4. Root Cause

The user account was locked after multiple unsuccessful login attempts.

## 5. Troubleshooting and Resolution

1. Confirmed the user's identity before proceeding.
2. Checked the account status in the simulated directory environment.
3. Identified the locked account.
4. Simulated an authorized account unlock.
5. Asked the user to try logging in again.
6. Confirmed that the login was successful.

## 6. Prevention

- Check the keyboard layout before entering a password.
- Avoid repeated unsuccessful login attempts.
- Contact the IT Service Desk if the account remains locked.

## 7. Final Result

**Status:** Resolved

The user was able to log in successfully after the simulated account unlock.
